# miniguia-estudos-notebooklm
Nesse estudo de base de IA generatica, irei utilizar a ferramenta da google notebooklm/notebook gemini.
Irei montar uma fonte de dados bem completa e robusta com o tema de fundamentos de CLOUD.
O objetivo desse projeto é entender como funciona a pesquisa de dados de uma IA, entender como ela funciona, e como ela pode otimizar as tarefas diarias, facilitando para trabalhos manuais e repetitivos. E também para ver as diferentes manipulações que a IA generativa consegue trabalhar com base nos dados fornecidos pelo usuario, podendo criar relatorios, graficos, cards ankis, podcasts, slides, resumos, videos, entre diversas outras formas de exibição de informações, facilitando a compreensão e organização de temas.
A ferramenta notebooklm entrega diversas funcionalidades que irão auxiliar no desenvolvimento de alguma tarefa, melhorando o desempenho e agilidade para resolver aquilo, ele é utilizado originalmente como uma forma didadica para concentrar uma base de dados solida pré definida pelo usuario criador do notebook.
Meus objetivos com o estudo das IAs generativas, é a compreensão fundamental do estudo de IAs, LLMs e outros temas extremamente imporante acerca do tema de IAs generativas, buscar compreender como posso usar a IA para facilitar meu trabalho no dia a dia, e como posso otimizar tempo.

O tema escolhido para o meu treinamento de base de IA generativa e para estudo pessoal, foi o tema de cloud computing, consegui juntar algumas fontes de informações importantes que o notebooklm irá juntar e fazer uma base de pesquisas que irão me auxiliar nos estudos e compreensão de forma mais organizada acerca do tema.
